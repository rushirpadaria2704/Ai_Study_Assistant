Custom API Configuration Guide
Supported Providers
  • OpenAI — key format: sk-..., default endpoint: https://api.openai.com/v1
  • Google Gemini — key format: AIza..., default endpoint: https://generativelanguage.googleapis.com/v1beta
  • Anthropic Claude — key format: sk-ant-..., default endpoint: https://api.anthropic.com/v1
  • Ollama (Local) — optional key, default endpoint: http://localhost:11434
  • Custom / OpenAI-Compatible — any endpoint exposing /chat/completions.
How to Add & Activate
  1. Click Add API Integration, select the provider type and enter credentials.
  2. Click Test Connection to verify API reachability and key validity.
  3. Save, then click the Activate button to make it the active provider.
  4. The app will prefer the active custom provider and gracefully fall back to Ollama.
